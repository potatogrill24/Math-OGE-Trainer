# Тренажер ОГЭ по математике
Сервис для репетитора по математике и его учеников: выдача домашних заданий, автоматическая проверка ответов и аналитика прогресса по номерам ОГЭ.

## Возможности
 
**Репетитор**
- Просмотр своих учеников и их контактной информации, расписание занятий
- Наполнение и просмотр банка задач (условие, номер ОГЭ, тема, сложность, эталонный ответ)
- Создание домашних заданий из банка и назначение ученикам
- Настройка правил выполнения: дедлайн, лимит попыток, режим показа ответов
- Просмотр сданных работ, ручная проверка развёрнутых решений
- Статистика по ученикам и группам: слабые номера ОГЭ, динамика
  
**Ученик**
- Профиль и расписание занятий
- Список назначенных домашних заданий, сдача ответов
- Мгновенный результат по задачам с автопроверкой
- Личная статистика по выполненным заданиям
  
## Архитектура
| Сервис | Ответственность | База данных |
|---|---|---|
| **Main** | Единая точка входа для фронтенда, проверка JWT и ролей, маршрутизация, агрегация данных для экранов | нет |
| **Auth** | Регистрация, логин, выдача и обновление JWT, роли пользователей | `users` |
| **Profile** | Профили учеников и репетиторов, связь репетитор ↔ ученик, расписание | `timetable` |
| **Content** | Банк задач и эталонные ответы | `tasks bank` |
| **Homework** | Домашние задания, назначения, сдачи, дедлайны, лимиты попыток, статусы | `homework` |
| **Check** | Проверка ответов, запись и выдача статистики | `stats` |

## Технологии
- **Backend:** Go, gRPC + Protocol Buffers (buf), PostgreSQL, JWT (RS256 + JWKS)
- **Frontend:** React, Vite
- **Инфраструктура:** Docker, Docker Compose
- **Наблюдаемость (план):** `log/slog`, OpenTelemetry, Prometheus, Grafana
- **Миграции:** goose
